## 2025-02-15 - [CRITICAL] Prevent Hardcoded JWT Secret Fallback
**Vulnerability:** The application used a hardcoded string ('your_jwt_secret_change_this') as a fallback for `JWT_SECRET` in both authentication middleware and routes. If the `JWT_SECRET` environment variable wasn't set, attackers could forge valid JWTs.
**Learning:** Hardcoded default secrets are a severe vulnerability because they are committed to version control and publicly known. Generating random fallback keys on startup introduces a separate vulnerability where active sessions are invalidated upon server restart and might cause load balancing issues or race conditions with imports.
**Prevention:** Always enforce a fail-fast startup. If a critical security parameter like a cryptographic key is missing, throw an immediate `Error` preventing the app from starting up rather than silently degrading into an insecure or transiently-secure state.

## 2024-05-24 - Unsanitized req.query in Mongoose and Regex Queries
**Vulnerability:** Found NoSQL injection and ReDoS vulnerabilities where `req.query` parameters (`type`, `genre`, `search`, `profileId`) were directly used in Mongoose queries without type checking or regex escaping.
**Learning:** In Express, `req.query` parameters can be parsed as objects/arrays if the client sends them with bracket notation (e.g. `?type[$ne]=xxx`). Passing these directly into Mongoose queries allows attackers to bypass intended logic (NoSQL injection). Additionally, using unsanitized user input in `$regex` queries without escaping special characters allows ReDoS attacks. Note that when validating optional parameters, we must check for presence (`!== undefined`) before checking type (`typeof !== 'string'`) to avoid returning errors for legitimately omitted parameters.
**Prevention:** Always enforce type checks (e.g. `typeof param === 'string'`) on optional query parameters before using them in database queries. For any user input used in `$regex`, always escape special characters using `replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.
